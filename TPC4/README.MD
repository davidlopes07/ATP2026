## Resumo do trabalho

Neste TPC, foi solicitado o desenvolvimento de um jogo em Python denominado "Corrida para o 100". O jogo consiste numa competição entre o utilizador e o computador, em que ambos jogam alternadamente, adicionando valores entre 1 e 10 a uma soma que começa em zero. O principal objetivo é atingir exatamente o valor 100, sendo declarado vencedor o primeiro jogador a consegui-lo.

O programa desenvolvido apresenta duas modalidades distintas: na primeira, o computador inicia a partida e utiliza uma estratégia que lhe garante a vitória; na segunda, o computador joga em segundo lugar, podendo ganhar ou perder consoante as decisões tomadas pelo adversário.
